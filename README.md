# Поиск по нормативным документам вуза — основа RAG

Высокоточная retrieval-система и микросервис гибридного поиска (Dense E5 + Sparse Char TF-IDF + Reciprocal Rank Fusion) по внутренним документам РТУ МИРЭА (положения об аттестации, отчислении, стипендиях, общежитиях).

## Архитектура и пайплайн

```
PDF → текст → очистка → нарезка на чанки (sentence chunking с перекрытием)
  ├── Sparse Index: Символьные n-граммы TF-IDF (char_wb 3-5)
  └── Dense Index: multilingual-e5-small (нормированные эмбеддинги, косинусная близость)
        │
        ├── Min-Max Fusion (alpha=0.5): взвешенное смешивание нормализованных скоров
        └── RRF (Reciprocal Rank Fusion, c=60): робастное ранжирование без гиперпараметров
              │
              ▼
       FastAPI Microservice (Pydantic v2, latency ~18ms, Healthcheck, Metrics)
```

## Бенчмарки и сравнение подходов

Оценка на размеченном золотом наборе из **18 запросов** (`eval_set.py`):
Метрики: **Recall@k** (доля релевантных документов в топ-k) и **MRR@10** (Mean Reciprocal Rank — чувствительность к точному рангу).

| Метод ранжирования | Recall@1 | Recall@3 | Recall@5 | MRR@10 |
|---|:---:|:---:|:---:|:---:|
| TF-IDF (по словам) | 0.500 | 0.778 | 0.944 | 0.659 |
| TF-IDF (символьные 3-5 n-граммы) | 0.611 | 1.000 | 1.000 | 0.787 |
| Эмбеддинги (`multilingual-e5-small`) | 0.778 | 1.000 | 1.000 | 0.870 |
| **Гибрид RRF (Reciprocal Rank Fusion)** | **0.778** | **1.000** | **1.000** | **0.870** |
| **Гибрид Min-Max (alpha = 0.5)** | **0.833** | **1.000** | **1.000** | **0.917** |

### Ключевые инсайты:
1. **Преодоление словарного разрыва (Vocabulary Mismatch):** В вопросах вроде «сколько раз можно пересдавать экзамен» лексический поиск пасует, так как в документе пересдача называется «повторной промежуточной аттестацией». Эмбеддинги поднимают релевантный фрагмент за счёт семантики.
2. **Морфологическая устойчивость:** Символьные n-граммы (`char_wb`) нейтрализуют флексии русского языка дешевле стемминга/лемматизации, поднимая recall@1 с 0.500 до 0.611.
3. **Синергия в гибриде:** Min-Max нормализация скоров с весом `alpha = 0.5` дала наивысший результат (**Recall@1 = 0.833, MRR = 0.917**), устраняя слепые зоны семантического поиска по редким аббревиатурам и точным числовым регламентам.

## Запуск сервиса

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск тестов (100% pass)
pytest tests/ -v

# Запуск FastAPI микросервиса
uvicorn api:app --host 0.0.0.0 --port 8000 --reload
```

## API Эндпоинты

- `GET /health` — проверка статуса сервиса, размера индексов и моделей.
- `POST /api/v1/search` — поисковый эндпоинт с Pydantic валидацией параметров (`hybrid`, `rrf`, `dense`, `sparse`).
- `GET /api/v1/benchmarks` — выдача актуальных замеров качества поиска.
